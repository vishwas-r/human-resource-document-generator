# Human Resource Document Generator 📄

A lightweight, high-aesthetic web tool for HR teams, managers, and employees to instantly customize, preview, and download official HR letters and certificates.

## ✨ Supported Document Templates

1. 🏠 **Employee Address Verification Letter** — Official verification proof for house owners and landlords.
2. 🛡️ **No-Objection Certificate (NOC)** — NOC for passport, travel, visa, higher studies, or side projects.
3. 📜 **Relieving & Experience Letter** — Formal release, tenure, designation, and conduct certificate.
4. 🎓 **Internship Completion Certificate** — Internship tenure, project domain, mentor, and performance recommendation.

## 🚀 Features

- ⚡ **Real-time A4 Live Preview**: Instant two-way data sync between form controls and the printable A4 letterhead canvas.
- 🎨 **Brand Color Picker**: Customize primary accent colors with interactive picker & swatches.
- 📄 **100% Vector PDF Export**: Uses programmatic `jsPDF` text rendering for crisp, searchable, selectable, and non-blurry PDFs.
- 🏢 **Corporate Branding**: Upload custom company logos and authorized digital signatures.
- 🧼 **Smart Blank Handling**: Gracefully hides empty labels, empty brackets, and optional sections when fields are left blank.
- 🖨️ **Browser Print Ready**: Native `@media print` CSS for clean 1-page A4 printing (`Ctrl + P`).

## 🛠️ Tech Stack

- **Bootstrap 5 & CSS3**: Responsive UI, form accordions, nav pills, A4 canvas layout system, Google Fonts (`Outfit`, `Merriweather`, `Inter`).
- **JavaScript (Vanilla ES6)**: Multi-document template state engine and dynamic sentence rendering.
- **jsPDF**: Programmatic client-side PDF document generation.
- **Feather Icons**: Crisp SVG UI icons.
